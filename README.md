# AImadeNbackgame
Nback game by gemini3

### ver 0.0

> NバックゲームをJavaScriptで
> 
> Nバックのルール
> Nを決めておく（1-5)。1から5を書いたカードが50枚ランダムに用意される。
> カードが１枚ずつめくられる。指定したNにあわせてN枚前と同じのが出たらNバックボタンを押せば正解。押せなかったら不正解。
> めくられたカードは過去５枚分、裏返しで画面に表示されている。
> 
> カード全部めくったらゲーム終了。正答率が得点になる。

### ver 0.1

> カードが変わる時u

-- ここで間違ってリターンを押したが上手くできた

「カードが変わる時に動き（アニメーション）をつけて分かりやすくしてほしい」というご要望と解釈しました。（もし「音（sound）」や別の意味でしたら教えてください！）

現状だと、同じ数字が続いた場合（例：3 → 3）に「画面が止まっているのか、新しいカードなのか」が分かりにくいため、カードが出る瞬間に「ポンッ」と拡大して表示されるアニメーションを追加しました。

これでリズムが掴みやすくなります。
